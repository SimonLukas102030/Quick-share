Potenzgleichungen verstehen

Was ist eine Potenzgleichung?

Eine Potenzgleichung ist eine Gleichung, in der die Variable als Basis einer Potenz auftritt. Die allgemeine Form lautet:

xn = a

Dabei ist n der Exponent (eine positive ganze Zahl) und a eine reelle Zahl.

Grundprinzip der Lösung

Um eine Potenzgleichung zu lösen, ziehen wir die n-te Wurzel auf beiden Seiten:

x = ⁿ√a
Wichtig: Die Anzahl der Lösungen hängt vom Exponenten und vom Vorzeichen von a ab!

Regeln für Lösungen

  • Gerader Exponent (n = 2, 4, 6, ...):
    • Wenn a > 0: Zwei Lösungen: x = ±ⁿ√a
    • Wenn a = 0: Eine Lösung: x = 0
    • Wenn a < 0: Keine reellen Lösungen
  • Ungerader Exponent (n = 3, 5, 7, ...):
    • Für jeden Wert von a: Genau eine Lösung: x = ⁿ√a

Lösungsschritte im Detail

  1. Gleichung in die Form xn = a bringen (Umstellen)
  2. Überprüfen, ob der Exponent gerade oder ungerade ist
  3. Überprüfen, ob a positiv, negativ oder null ist
  4. Die n-te Wurzel ziehen (bei geradem n: ± nicht vergessen!)
  5. Probe machen: Lösungen in die ursprüngliche Gleichung einsetzen

Beispiele

Beispiel 1: x² = 25

Exponent: 2 (gerade)

Rechte Seite: 25 (positiv)

Lösung: x = ±√25 = ±5

Probe:

  • x₁ = 5: 5² = 25 ✓
  • x₂ = -5: (-5)² = 25 ✓

Beispiel 2: x³ = -8

Exponent: 3 (ungerade)

Rechte Seite: -8 (negativ)

Lösung: x = ³√(-8) = -2

Probe: (-2)³ = -8 ✓

Beispiel 3: x⁴ = -16

Exponent: 4 (gerade)

Rechte Seite: -16 (negativ)

Lösung: Keine reellen Lösungen!

Begründung: x⁴ ist immer positiv oder null, kann also nie -16 sein.

Komplexere Gleichungen

Manchmal muss die Gleichung erst umgeformt werden:

Beispiel: 3x² - 12 = 0

Schritt 1: Umformen

3x² = 12

x² = 4

Schritt 2: Lösen

x = ±√4 = ±2

Beispiel: (x - 1)³ = 27

Schritt 1: Wurzel ziehen

x - 1 = ³√27 = 3

Schritt 2: Nach x auflösen

x = 3 + 1 = 4
