# Start
## Spieler sind in Ihren häusern
- Den spielern fehlt ein besonderer Gegenstand
- Sie erinnern sich, dass sie letztens, in der Taverne davon gehört hatten, dass Sachen verschwinden.
### Taverne
- Name: Zum Goldhorn
- Location: In der nähe vom Markt beim Rahthaus von Vandoria
## Spieler gehen zur Taverne
- Taverne sehr voll
- Werden begrüßt von Wirt Greg
- Greg weißt auf 4er Tisch mit Yarris
### Yarris
- Viele Sachen verschwinden - Besonders Gold
- Vermutet Goblins
#### Für preis: 2 bronze
- Scheinen erher taktisch vor zu gehen
- schließt auf einen koordinator
